# Phase 7 — Plan 07-03: Frontend Inbox, Notification Bell, Review & Safety Modals (Wave 3)

## 1. Goal
Build the frontend user interfaces for in-app messaging, real-time notification alerts, post-session peer review submission, and safety reporting.

## 2. Deliverables
1. **Direct Messaging Interface (`frontend/src/pages/MessagesPage.tsx` at `/messages`):**
   - Protected route.
   - Responsive two-column layout:
     - Left pane: Conversation list with counterparties' avatars, online/recent status, last message snippet, and unread indicator.
     - Right pane: Active chat thread with chronological bubbles (emerald for sent, slate for received), timestamp, counterparty profile link, and text composer with send button.
2. **Notification Bell Component (`frontend/src/components/notifications/NotificationBell.tsx`):**
   - Bell icon in `Navbar.tsx` with dynamic red badge for unread count.
   - Dropdown card showing recent alerts (sessions, matches, credits, reviews) with timestamps.
   - One-click "Mark All Read" action.
3. **Peer Review Modal (`frontend/src/components/reviews/ReviewModal.tsx`):**
   - 5-star interactive rating selection (gold fill).
   - Written feedback textarea.
   - Triggered directly from the "Completed Sessions" tab on `/sessions` or partner profiles.
4. **Safety Report Modal (`frontend/src/components/reports/ReportModal.tsx`):**
   - Category selector (Misconduct, No-Show, Harassment, Safety concern).
   - Description input and confidential submission confirmation.
5. **Navigation & Route Integration:**
   - Update `Navbar.tsx`: Add "Messages" nav link and mount `NotificationBell`.
   - Update `App.tsx`: Mount `<Route path="/messages" element={<ProtectedRoute><MessagesPage /></ProtectedRoute>} />`.
6. **Verification:**
   - Automated Node test suite (`backend/test/phase7Verification.js`) verifying conversation threads, message sending, notifications, review recalculation, and report submission.
   - Frontend production build (`tsc -b && vite build`) passing with zero errors.

## 3. Acceptance Criteria
- [ ] Users can browse conversations, open a thread, and send messages.
- [ ] Notification bell displays unread badge and dropdown with recent events.
- [ ] Submitting a review from `/sessions` updates the provider's rating.
- [ ] Safety reports can be submitted securely.
- [ ] Production build succeeds without TypeScript or bundling errors.
