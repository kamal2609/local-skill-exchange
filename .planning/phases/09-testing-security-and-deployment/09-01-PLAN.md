# Phase 9 — Plan 09-01: Master Automated Test Suite & Testing Harness (Wave 1)

## 1. Goal
Unify all verification suites into a comprehensive, single-command automated test suite in `backend/test/masterTestSuite.js`, and wire up `"npm test"` across the monorepo for instant continuous testing.

## 2. Deliverables
1. **Master Test Runner (`backend/test/masterTestSuite.js`):**
   - Single-file automated test harness running against an ephemeral HTTP server on random port `0`.
   - Executes 140+ assertions across 7 core functional suites:
     - **Suite 1: Auth & User Profiles:** Registration, login, JWT token generation, role verification, profile updates.
     - **Suite 2: Skills & Catalog:** Taxonomy, skill offers, learning requests, tag filters.
     - **Suite 3: Smart Skill Matching Engine ⭐:** Mathematical scoring validation (direct match, category bonus, language overlap, distance decay, reciprocal barter bonus, normalization [0, 100]).
     - **Suite 4: Availability & Session Booking:** Conflict prevention, state machine transitions (`REQUESTED → ACCEPTED → CONFIRMED`), dual-confirmation logic.
     - **Suite 5: Time-Banking Credit Ledger:** 1 hour = 1 credit accounting, double-entry symmetry, non-negative balance enforcement, duplicate reward prevention, admin adjustments.
     - **Suite 6: Communication & Community:** Direct 1-on-1 messaging, notification dispatch, 5-star peer reviews, safety report submission.
     - **Suite 7: Admin Control Center:** Platform KPI aggregations, user account suspension/reactivation, report moderation resolution, taxonomy registration.

2. **Package Configuration Updates:**
   - Update `backend/package.json` with `"test": "node test/masterTestSuite.js"`.
   - Update root `package.json` with `"test:backend": "npm run test --prefix backend"`, `"test": "npm run test:backend"`.

3. **Frontend Test Verification:**
   - Add frontend testing utility script or validation ensuring client-side formatting and matching calculation parity.

## 3. Acceptance Criteria
- [ ] Running `npm test` from root executes the entire backend test suite.
- [ ] 100% of test assertions pass with zero failures.
- [ ] Ephemeral server cleans up gracefully with exit code 0.
- [ ] Works seamlessly in both connected MongoDB Atlas and offline fallback modes.
