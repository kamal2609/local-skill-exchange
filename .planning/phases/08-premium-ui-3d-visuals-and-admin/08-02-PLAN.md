# Phase 8 — Plan 08-02: 3D Visuals & Framer Motion Micro-Interactions (Wave 2)

## 1. Goal
Elevate the visual presentation and physical feel of the application using Three.js / React Three Fiber for a rich interactive 3D skill network hero and Framer Motion for smooth page transitions and card physics.

## 2. Deliverables
1. **Enhanced 3D Skill Network Hero (`frontend/src/components/three/SkillNetworkHero.tsx`):**
   - **Constellation Edges:** Render dynamic lines (`THREE.LineSegments` or SVG overlay) linking adjacent skill nodes to visualize the barter exchange mesh.
   - **Interactive Node Hover:** Scale nodes up on hover with subtle emission glow.
   - **Interactive Skill Labels:** Render floating 2D/3D badge tooltips (e.g., *"Python"*, *"Spanish"*, *"Gardening"*, *"Guitar"*, *"Sourdough"*, *"Graphic Design"*) when hovering over nodes.
   - **Performance & Mobile Fallback:** Add WebGL support detection and responsive window resize handling; automatically render an animated CSS SVG constellation for mobile devices or environments without hardware acceleration.

2. **Framer Motion Route Transition Component (`frontend/src/components/shared/PageTransition.tsx`):**
   - Wrap page content with `<motion.div>` featuring smooth entrance opacity and slight vertical rise (`y: 12 → 0`).
   - Clean exit transitions with exit animations.

3. **Micro-Interactions Across Existing Pages:**
   - Add hover elevation, subtle tap scale (`whileTap={{ scale: 0.98 }}`), and staggered list animations to:
     - Skill offer & request cards in `ExplorePage.tsx`
     - Smart match partner cards in `MatchesPage.tsx`
     - Booking cards in `SessionsPage.tsx`
     - Action buttons and pills across navigation.

## 3. Acceptance Criteria
- [ ] 3D canvas loads smoothly on modern desktop browsers with 60 FPS floating rotation.
- [ ] On mobile screens or devices where WebGL fails, the fallback renders seamlessly without errors.
- [ ] Route changes trigger smooth fade-in transitions without layout jump.
- [ ] Interactive cards provide tactile hover/tap feedback.
- [ ] Production build (`tsc -b && vite build`) passes with zero TypeScript warnings or bundling errors.
