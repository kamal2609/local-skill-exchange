# Phase 8 — Plan 08-03: Admin Dashboard & 20 Application Pages (Wave 3)

## 1. Goal
Complete all 20 application page views by implementing the Admin Command Center (`/admin`), dedicated educational and community pages (`/about`, `/how-it-works`, `/safety`, `/community`), and mounting them with appropriate route protections and navigation links.

## 2. Deliverables
1. **Admin Route Guard (`frontend/src/components/shared/AdminRoute.tsx`):**
   - Restricts `/admin` route to authenticated users with `user.role === 'ADMIN'`.
   - Redirects unauthenticated users to `/login` and non-admin users to `/`.

2. **Admin Dashboard Page (`frontend/src/pages/AdminDashboardPage.tsx`):**
   - **Tab 1: Platform Overview & KPIs:** Live cards for Total Members, Active Skills, Completed Sessions, Credit Volume, Pending Reports, and Quick Health status.
   - **Tab 2: User Management:** Search by name/email, filter by role/status, toggle account active/suspended (`PUT /api/admin/users/:id/status`), and modify role.
   - **Tab 3: Trust & Safety Moderation:** List pending user reports, view violation reason and description, open moderation action dialog to mark `RESOLVED` or `DISMISSED` with admin audit notes.
   - **Tab 4: Skill Taxonomy Manager:** View current skill categories and create new categories via `POST /api/admin/categories`.
   - **Tab 5: Time-Banking Credit Audits:** Manual credit adjustment tool invoking `POST /api/credits/admin-adjust` with mandatory reason logging.

3. **Remaining Application Page Views (Completing the 20 Views):**
   - **`frontend/src/pages/AboutPage.tsx` (`/about`):** Philosophy of egalitarian time-banking (1 hour = 1 credit), community story, FAQ, and core principles.
   - **`frontend/src/pages/HowItWorksPage.tsx` (`/how-it-works`):** 4-step visual flow: 1. Post a Skill → 2. Smart Match → 3. Book a Session → 4. Exchange Credits.
   - **`frontend/src/pages/SafetyGuidelinesPage.tsx` (`/safety`):** Trust and safety code of conduct, safe meeting standards, zero-tolerance policy, and dispute resolution.
   - **`frontend/src/pages/CommunityPage.tsx` (`/community`):** Neighborhood community leaderboard, top skill teachers, recent skill exchange highlights, and testimonials.

4. **Routing & Navigation Integration:**
   - Update `frontend/src/App.tsx` with `/admin`, `/about`, `/how-it-works`, `/safety`, and `/community`.
   - Update `frontend/src/components/Navbar.tsx` to display an "Admin" badge/link in the header when `user.role === 'ADMIN'`.
   - Update `frontend/src/components/Footer.tsx` with links to About, How It Works, Safety Guidelines, Community, and Explore.

5. **Automated Verification Suite (`backend/test/phase8Verification.js`):**
   - Ephemeral server testing admin authentication guards, metric retrieval, user status toggles, and report resolution.

## 3. Acceptance Criteria
- [ ] `/admin` accessible only to users with role `ADMIN`; unauthorized users redirected.
- [ ] Admin dashboard displays live metrics from `GET /api/admin/metrics`.
- [ ] User status toggles update user `isActive` flag in real time.
- [ ] Safety reports can be marked `RESOLVED` or `DISMISSED` with admin notes.
- [ ] All 20 application routes load cleanly without 404 or compilation errors.
- [ ] Automated verification test suite passes 100%.
- [ ] Frontend production build (`tsc -b && vite build`) succeeds with zero errors.
