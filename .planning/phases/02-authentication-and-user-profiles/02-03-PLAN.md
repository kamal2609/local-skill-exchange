# Phase 2 — Plan 02-03: Frontend Auth State, Routes & UI Pages (Wave 3)

## 1. Goal
Provide a seamless, responsive frontend experience with persistent authentication state, protected routes, login, registration, password recovery, and profile view/edit screens.

## 2. Deliverables
1. `frontend/src/context/AuthContext.tsx`:
   - React context managing `user`, `token`, `isAuthenticated`, `isLoading`, `login`, `register`, `logout`, `updateProfile`.
   - Token stored in `localStorage` ('lse_token') and attached to all Axios requests via header interceptor.
   - Initial bootstrap calls `GET /api/auth/me` to restore user session on page refresh.
2. `frontend/src/components/shared/ProtectedRoute.tsx`:
   - Checks auth status; redirects to `/login` if not logged in.
   - Checks allowed roles if specified; redirects to `/` if unauthorized.
3. Auth Pages:
   - `frontend/src/pages/LoginPage.tsx`: Email/username & password login, error alerts, redirect to intended path or home.
   - `frontend/src/pages/RegisterPage.tsx`: Name, username, email, password, bio, city, role selection, with badge highlighting the 3.0 Welcome Credits.
   - `frontend/src/pages/ForgotPasswordPage.tsx`: Request password reset email/link.
   - `frontend/src/pages/ResetPasswordPage.tsx`: Enter new password with verification.
4. Profile Pages:
   - `frontend/src/pages/ProfilePage.tsx`: View & edit profile, tabbed sections for personal details, skills offered/wanted, and credit status.
   - `frontend/src/pages/PublicProfilePage.tsx`: Public view of any community member with stats, bio, and teaching offers.
5. Navbar & App Integration:
   - Update `Navbar.tsx` to dynamically display:
     - Login / Register buttons when unauthenticated.
     - Live Credit Badge (showing real `user.creditsBalance`), User Avatar, Name, and Logout dropdown when logged in.
   - Update `App.tsx` with all new routes wrapped in `AuthProvider`.

## 3. Acceptance Criteria
- [ ] Users can register, log in, and log out with immediate UI state updates.
- [ ] Navbar dynamically updates with the authenticated user's name and credit balance.
- [ ] Protected routes block unauthenticated access and redirect to `/login`.
- [ ] Profile page allows updating bio, city, languages, and preferred learning mode.
- [ ] Production build (`npm run build --prefix frontend`) succeeds without TypeScript or bundling errors.
