# Phase 6 — Plan 06-03: Time-Banking Ledger UI & Navbar Integration (Wave 3)

## 1. Goal
Build the frontend Time-Banking Ledger page (`/ledger`) visualizing credit balances, lifetime hours taught and learned, filterable transaction history, and link it to the global navigation.

## 2. Deliverables
1. **`frontend/src/pages/LedgerPage.tsx` (`/ledger`):**
   - Protected route.
   - Header with Time-Banking parity badge: "1 Hour = 1 Credit | Equality-Based Accounting".
   - Balance Summary Hero:
     - Prominent current balance display (with pulsing clock icon).
     - Lifetime Hours Taught (Total Credits Earned).
     - Lifetime Hours Learned (Total Credits Spent).
     - Total Completed Sessions count.
   - Transaction History Ledger:
     - Filter tabs: "All Transactions", "Credits Earned (+)", "Credits Spent (-)", "Welcome Bonuses".
     - Table / Card view:
       - Date and time.
       - Transaction type badge (with color coding: `SESSION_EARN` in emerald, `SESSION_SPEND` in amber, `WELCOME_BONUS` in purple).
       - Counterparty (avatar, name, role).
       - Amount ($+1.0$ or $-1.0$ Cr).
       - Description / Reference note.
   - Export feature: Simple CSV download for user's personal records.
2. **Navigation Integration:**
   - Update `frontend/src/components/Navbar.tsx`:
     - Update the credits pill in the navbar so clicking it navigates to `/ledger`.
3. **Route Integration:**
   - Update `frontend/src/App.tsx`:
     - Mount `<Route path="/ledger" element={<ProtectedRoute><LedgerPage /></ProtectedRoute>} />`.
4. **Verification:**
   - Automated Node test suite (`backend/test/phase6Verification.js`) verifying balance queries, session credit settlements, solvency invariants, and ledger pagination.
   - Frontend production build (`tsc -b && vite build`) passing with zero errors.

## 3. Acceptance Criteria
- [ ] Navigating to `/ledger` while authenticated displays balance and history.
- [ ] Credits pill in Navbar links to `/ledger`.
- [ ] Filter tabs filter transactions cleanly by type.
- [ ] Production build succeeds without TypeScript or bundling errors.
