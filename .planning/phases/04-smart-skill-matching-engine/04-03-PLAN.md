# Phase 4 — Plan 04-03: Smart Matches Dashboard UI & Partner Comparison View (Wave 3)

## 1. Goal
Build the Smart Matches Dashboard page (`/matches`) that visualizes recommended partners, displays compatibility percentages, shows the 6-factor score breakdown bar, highlights reciprocal matches, and integrates into the app navigation.

## 2. Deliverables
1. **`frontend/src/pages/MatchesPage.tsx` (`/matches`):**
   - Protected route.
   - Header with differentiator banner: "Smart Skill Matching Engine ⭐ (AI-Free Explainable Compatibility Algorithm)".
   - Filter controls: "All Matches" vs "Reciprocal Only ⭐", Minimum Score Slider (20% to 80%).
   - Match Card Components:
     - Overall compatibility circle/pill with color coding:
       - 80%+ : Emerald (Excellent Match)
       - 50-79% : Teal (Good Match)
       - <50% : Amber (Moderate Match)
     - ⭐ **Reciprocal Skill Swap Badge** prominently displayed if reciprocal.
     - Partner Avatar, Name, City, and Rating.
     - **Skill Exchange Summary:**
       - "They can teach you:" [List of skills they offer that you want]
       - "You can teach them:" [List of skills you offer that they want]
     - **6-Factor Visual Compatibility Bar:**
       - Mini multi-segment progress bar showing Skill (40%), Reciprocal (25%), Schedule (15%), Experience (10%), Location (5%), Language (5%).
     - **"Why You Match" Accordion/List:**
       - Clear bullet points generated by the backend explanation engine.
     - **Action Buttons:**
       - "View Partner Profile" (`/users/:id`)
       - "Request Session (Phase 5 Booking)"
2. **Navigation Integration:**
   - Update `frontend/src/components/Navbar.tsx`:
     - Add **"Smart Matches"** nav link with a star badge (visible to authenticated users).
3. **Route Integration:**
   - Update `frontend/src/App.tsx`:
     - Mount `/matches` protected route.
4. **Verification:**
   - Vitest / Node test suite verifying the matching service formulas.
   - Frontend production build (`tsc -b && vite build`) passing with zero errors.

## 3. Acceptance Criteria
- [ ] Navigating to `/matches` while unauthenticated redirects to `/login`.
- [ ] `/matches` renders ranked partner cards with compatibility scores and explanations.
- [ ] Reciprocal matches display the golden "Mutual Skill Swap Available" badge.
- [ ] Filtering by "Reciprocal Only" shows only bilateral barter candidates.
- [ ] Navbar displays the Smart Matches link for logged-in users.
- [ ] Production build succeeds without TypeScript or bundling errors.
