# Phase 4 — Plan 04-02: Matching API Endpoints & Discovery Integration (Wave 2)

## 1. Goal
Expose the Smart Skill Matching Engine via Express REST API endpoints with authentication, filtering, pagination, and error handling.

## 2. Deliverables
1. **`backend/src/controllers/matchController.js`:**
   - `getSmartMatches`: `GET /api/matches`
     - Protected endpoint. Uses `req.user._id`.
     - Supports query parameters: `minScore` (e.g. 30), `limit` (e.g. 10), `reciprocalOnly` (boolean).
     - Returns ranked list of compatible partners with compatibility percentage, score breakdown, matching skills, and explanations.
   - `getReciprocalMatches`: `GET /api/matches/reciprocal`
     - Protected endpoint returning only reciprocal matches.
   - `getPartnerMatchDetail`: `GET /api/matches/:partnerId`
     - Protected endpoint returning detailed bilateral compatibility analysis between logged-in user and any specific partner.
2. **`backend/src/routes/matches.js`:**
   - Mounts `GET /`, `GET /reciprocal`, and `GET /:partnerId` guarded by `protect`.
3. **Mount `/api/matches` in `backend/src/app.js` and register in root discovery endpoint.**

## 3. Acceptance Criteria
- [ ] `GET /api/matches` rejects unauthenticated requests with HTTP 401.
- [ ] `GET /api/matches` with authenticated token returns HTTP 200 and array of ranked match results.
- [ ] `GET /api/matches/reciprocal` returns only results with `isReciprocal: true`.
- [ ] `GET /api/matches/:partnerId` returns detailed breakdown between authenticated user and requested partner.
- [ ] All match responses include `{ score, breakdown, isReciprocal, explanations, partner }`.
